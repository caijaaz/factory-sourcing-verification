# 找厂渠道矩阵（分层结构：12 主线渠道 + 可选受限层）

执行顺序：先跑「撒网层」主渠道广捞新面孔；线索枯竭后开「反查层」固定证据，对存疑候选补「实景核验层」与「出货铁证层」。所有渠道统一用 WebSearch，多角度用 query_keyword_groups 一次覆盖（最多 5 组），减少调用次数。

---

## 层 1：撒网层（主渠道，先跑，目的"广捞新面孔"）

### A. 政府/监管公开名录（权威源，生产资质铁证）
- 目标：行业主管部门《生产企业名录》、生产许可证公示、产业园区入驻企业名单
- 关键词：`{省份} {行业主管部门} {生产许可/生产企业} 名录 {年份}` / `{产业园区名} 入驻企业 名单 {产品类别}` / `{企业名} 生产许可证 许可范围`
- 产出：许可证书编号、许可范围、有效期 —— "生产资质"维度最硬证据
- 说明：不同品类主管部门不同（化工看应急管理厅、食品看市场监管、机械看工信等），开工前先对齐"该管谁"

### B. 行业 B2B 平台（线索量大，噪音也大）
- 平台：按品类选，如 1688、慧聪网、找钢网、各垂直行业平台
- 关键词：`{产品名} 生产厂家 {唯一标识}` / `{产品名} {唯一标识} 工厂 现货`
- 筛选：只看标注"生产型/工厂"且必须回查经营范围（平台标签"工厂"常是自封）；平台企业展台产品页挂具体产品 + 唯一标识，可作"目标产品在产"的强证据

### D. 行业协会名录
- 目标：细分行业协会会员名单
- 关键词：`{行业} 协会 会员单位 名录 {产品类别}`
- 特点：产出稳定但多为头部老面孔，适合补漏与背书

### E. 专利反向（挖隐形生产商）
- 目标：搜目标产品"制备方法/工业化生产"专利，看申请人是谁
- 关键词：`{产品名} 制备方法 专利 申请人` / `{产品名} 工业化生产 专利`
- ⚠️ 红线：专利申请人 ≠ 生产商。挖到后必须回反查层验生产许可

### F. 国际站英文 B2B（挖出口导向厂）
- 平台：Alibaba International、Made-in-China、TradeIndia 等
- 关键词：`{english product name} manufacturer China` / `{唯一标识} factory supplier China`
- ⚠️ 红线：英文站"manufacturer"自称完全不可信，一律回反查层核验

### L. 展会参展商名录（撒网主渠道：拿名单 → 筛品类 → 逐个核实）
- 目标：从行业展会参展商名单圈出目标品类企业，作为"别人帮你筛过一轮"的候选池，再逐个核实——**优先于 B2B 海捞，有对应展会时第一个跑**
- ⚠️ 定位：参展商名录是**候选来源**，不是**资质证明**——参展只证明交了展位费，不证明有产能。名录里每家企业必须走反查层（C）核实后才能进池
- 名单从哪拿（免费，不必买会刊）：
  1. 展会官网"参展商名录/展商查询"页（广交会、行业展官网，部分需注册）
  2. 展讯聚合平台名录页（展讯网/聚展网/去展网，免费预览部分）
  3. 行业协会/主办方会刊 PDF（协会办展的会刊≈会员名录，官网常挂）
  4. 政府/权威媒体开幕报道（新闻点名的重点展商）
  5. 国际展会 exhibitor list 页（EICMA/Interbike/Eurobike 等官网免费）
- 关键词：`{展会名} 参展商 名录 {年份}` / `{展会名} {产品} 参展商` / `{展会名} 展商名单` / `{品类} 展会 {年份} 参展商`
- 筛选：圈出目标品类进候选队列；老面孔跳过。注意：**新闻点名通常只覆盖整车/大牌，目标品类的完整名单要翻名录/会刊**
- 核实 4 步（参展只是起点）：反查层 C 查信用代码/经营范围/参保 → 按品类对认证 → 实景 H 查用工 → 分级落表
- 产业带提示：先摸清目标品类产业带（如头盔看温州乐清"中国头盔生产基地"、台州温岭/黄岩/玉环），产业带所在城市的行业展名录密度最高
- 双用途：参展记录兼作出货铁证层证据（证明该企业近期在卖在出）；L 升入撒网层后，出货铁证层不再重复列
- 靠谱度：免费；来源权威性排序：展会官网名录 > 协会会刊 > 展讯平台 > 媒体报道

## 层 2：反查层（对撒网线索做证据固定，验"资质真不真"）

### C. 资质反查（工商 + 海关 + 许可三连）
- 目标：拿到候选后，反查工商信息 + 海关注册编码 + 生产许可
- 关键词：`{企业名} 统一社会信用代码 经营范围` / `{企业名} 海关注册编码 进出口` / `{企业名} 生产许可证 许可范围`
- 数据源：企查查/天眼查/爱企查快照（仅作 Tier-0 快筛）、海关总署注册公示、行业主管部门公示
- 说明：商业聚合平台作快筛漏斗，终验必须回官方源头（平台自认"抓取数据仅供参考"）

---

## 层 3：实景核验层（补强"是不是真厂在产"——原 7 渠道最弱环节）

### H. 招聘平台反查（真实用工 = 真生产厂最硬信号）
- 目标：看厂是否在招产线岗位（操作工/工艺工程师/质检），规模与产能是否匹配
- 平台：BOSS 直聘、前程无忧、智联招聘
- 关键词：`{企业名} 招聘 操作工` / `{企业名} 工艺工程师 薪资` / `{企业名} 普工 待遇`
- 判读：长期招产线工 + 岗位含工艺/设备 = 真生产；只招销售/外贸 = 疑似贸易商；工商参保个位数却自称大厂 = 壳
- 靠谱度：免费、实打实，比工商参保数更准（参保数可美化）

### H+. 联系方式升级（两轮：先销售线，再老板线）
- 目的：撒网/反查层默认捞到的 400 热线、官网邮箱是"前台/总机"，不是能拍板的人。本子节把公开渠道里可拿到的直拨手机 + 微信挖出，回填 Excel「联系方式」列，让交付物能直接询盘。
- **第一轮·销售/外贸线**（默认跑，零成本、命中率高，已知厂名时全跑）：
  1. **1688 / 阿里国际站店铺页** —— 销售经理手机 + 微信直接挂首页（🟢高）
  2. **微信搜一搜 / 公众号 / 视频号「联系我们」** —— 销售手机 + 微信（🟢高）
  3. **展会参展商名录**（行业展会官网 PDF） —— 参展联系人手机（🔴铁证，且兼作出货铁证层佐证）
- **第二轮·老板/决策线**（买方订单量大、想绕开中间层时**主动跑**；很多小微企业法人即业务员，跳过这轮等于白丢一半命中率）：
  1. **政府环评/招投标公示的「建设单位联系人」** —— 🔴 **最强**。政府网站公示、面向公众征集意见，通常直通决策层（实测命中过"金先生 137xxxx"＝持股 60% 法人的同姓联系人）
  2. **企业年报公示手机** —— 小微企业年报留的号常即老板本人
  3. **B2B 平台「企业联系人」栏** —— 黄页类站点常直接写法人姓名+手机（如`联系人:项灵军 手机:159xxxxxxxx`）
  4. **招聘岗位发布人** —— 外贸/电商岗的发布人往往是老板或部门头，且发布人常同时留手机+微信
  5. **地方企业名录**（政企查查等政务/工商数据导出站）—— 带「联系电话」列，含**分公司**注册号（分公司负责人常是法人本人）
  6. **COTV / 中网市场等行业宣传页** —— 常直接挂「总经理某某携全体同仁欢迎光临」+ 本人手机
- 辅助渠道（按需）：抖音/快手企业号主页留联（🟡中高）、总机 cold call 转外贸部（🟡中）
- 回填规范：
  - 来源标证据强度：🔴铁证（政府公示/官网/展会名录直列）/ 🟢强证（B2B 黄页或跨平台一致，注明几处一致）
  - 写法示例：`老板本人直拨(强证·黄页3处一致): 李某某13900000000; 总机0571-xxxx; sales@xxx.com; www.xxx.com`
  - 手机放最前，并注明**该号是谁的**（法人本人 / 总经理 / 外贸部对接人 / 销售），便于买方按决策链分层首拨
  - 同企业多个手机按「年报年份」或「来源」并列，标出哪个最新 —— 老号可能已随人员离职失效
- 合规边界（**修正版**，按"信息是否为企业公示/公开发布的商业联系信息"划线，而非按"职务"一刀切）：
  - ✅ **可取**：企业年报公示电话、政府公示联系人、B2B 平台企业联系人栏、招聘发布人、企业官网/宣传页挂出的负责人号 —— 这些属《企业信息公示暂行条例》要求公示或企业**主动公开用于商业联系**的信息，用于 B2B 商务洽谈合规
  - ❌ **不取**：个人社交媒体私号、从数据泄露/灰产渠道获得的号、与业务无关的私人号
  - 📌 注意：小微企业「法人＝业务员」是常态，法人手机常就是企业唯一商务入口；一刀切排除法人号会让小厂线索直接断层。**正确做法是取用但标注来源与身份**，让买方自行判断
  - 📌 买方若明确要求"要老板号、不想被销售层抽利润"，按第二轮跑；同时提示现实：大厂法人不接销售电话（会被转外贸部），且**真正的利润漏点在"贸易商 vs 工厂"，不在工厂销售岗**（销售是拿工资的，不是抽佣中间商）——把力气花在验证主体是厂还是贸易商上更值
- 验证经验：聚合平台/黄页号偶现「销售离职仍挂旧号」，首拨先确认是否仍负责目标产品外销；同企业多平台号码打架时以**最新年报**为准

### I. 地图/卫星 POI 反查（看实地是不是厂）
- 目标：确认厂址在产业园/工业区而非写字楼，卫星图看厂房/堆场面积
- 平台：高德地图、百度地图、Google Earth（卫星）
- 关键词：`{企业名} 地址` / `{企业名} 厂房 卫星图` / `{产业园名} 企业分布`
- 判读：注册在写字楼且无实地厂房 = 贸易商/壳；在正规产业园 + 卫星可见连片厂房 = 真厂概率高
- 靠谱度：免费、直观

### J. 短视频/内容平台实拍（产能肉眼可见）
- 目标：搜厂名看产线实拍、车间视频，验证真实产能与工艺
- 平台：抖音、视频号、小红书
- 关键词：`{企业名} 工厂实拍` / `{产品名} 生产线 厂家`
- 判读：有产线实拍 + 车间规模 = 强佐证；纯产品摆拍无产线 = 弱
- 靠谱度：免费但噪音大，作辅助佐证，不单独下结论

## 层 4：出货铁证层（补强"真的在卖/在出"——比产品页更硬）

### G. 招标采购反查（证明最近真在卖）
- 目标：搜科研院所/企业对该产品的招标中标公告，中标方即活跃供应商
- 关键词：`{产品名} 采购 中标 公示` / `{产品名} 招标 结果`
- 特点：能证明"最近真的在卖"，但中标方常是贸易商，仍需反查层核验

### K. 上市公司年报/招股书供应商名单（权威背书，被大客户审计过的真厂）
- 目标：细分行业龙头的年报/招股书会披露前五大供应商，全是经审计的真厂
- 平台：巨潮资讯、上交所、深交所、北交所
- 关键词：`{下游龙头公司} 招股书 前五大供应商` / `{行业} 年报 主要供应商名单`
- 产出：被头部客户验证过的真厂名单，可信度极高，适合找"行业里已被大客户背书"的厂
- 靠谱度：免费、权威

> 注：L（展会参展商名录）已升入撒网层，其"参展记录"兼作出货铁证证据，本层不再重复列。

## 层 5：可选受限层（不进主线，按需开启，标注清楚边界）

### M. 海关报关数据反查（企业级需付费）
- 说明：中国出口报关数据免费公开仅到 HS 编码层面、不到企业名；企业级报关记录多在付费平台（特易、PANJIVA、ImportGenius）
- 用途：证明"真实出口记录 = 真产能铁证"，有预算再走，不写进主线以免团队空耗
- 关键词：`{企业名} 海关数据 出口记录`（在付费平台内查）

## 渠道通用纪律

1. 每轮搜索后立刻记录：新面孔（进核验队列）/ 老面孔（跳过）/ 弱信号（挂起）
2. 同一企业以统一社会信用代码为准对人，防重名
3. 分层执行顺序：撒网层 → 反查层 → 实景核验层 → 出货铁证层；可选层按需开启
4. 渠道枯竭判定：撒网层连续 2-3 轮只出老面孔 → 切下一层或收工汇报
