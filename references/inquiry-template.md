# 问厂话术模板（电话 + 邮件）

用途：对 Tier-1/Tier-2 候选做最终确认。公开信息只能把候选推到"高置信"，成交前的最后一公里靠这套话术。

## 电话四连问（通用）

开场：您好，我们是做 {产品名} 采购/出口的公司，有 {数量/柜型} 的订单在谈，想确认几个信息。

1. **在产确认**：{产品名}（{唯一标识，如 CAS/型号}）{规格} 目前是正常在产吗？现货还是排产？交期多久？
2. **起订量与产能**：起订量多少？月产能多少？{目标数量} 能不能吃下？
3. **资质三件套**：
   - 生产许可证/行业许可的许可范围里有 {产品名} 吗？证在有效期内吗？（关键：让对方念证号和范围，回头可查）
   - 贵司有自营进出口权吗？海关注册编码方便提供吗？
   - 能否随货提供该品类要求的合规文件？（按品类而定，如危化品需 MSDS/危包证/COA、食品需 SC/质检报告、机械需 CE/质检报告等）
4. **物流与文件**：出口走过该类产品吗？所需运输/报关文件齐吗？港口选哪个？

收尾：方便加个微信/留个邮箱吗？我把具体规格发您，麻烦报个 FOB 价。

## 邮件模板

主题：{产品名}（{唯一标识}）{数量} 采购询价——{公司名}

{厂家} 您好：

我司正在采购 {产品名}（{唯一标识}），需求如下：
- 规格：{浓度/型号/纯度}
- 数量：{数量}（约 {柜型}）
- 包装：{要求}
- 目的港：{港口}

烦请确认并回复：
1. 该产品当前是否在产，交期与月产能；
2. 贵司《生产许可证/行业许可》许可范围是否包含该产品（如可，请附证书扫描件）；
3. 是否具备自营进出口权（海关注册编码）；
4. 能否提供该品类要求的合规文件（MSDS/质检报告/运输文件等，按品类而定）；
5. FOB {港口} 报价及有效期。

期待回复。
{署名 / 联系方式}

## 回复甄别要点

- 支支吾吾不肯给许可证号/许可范围 → 大概率证上没有该品，降级或踢
- 说"可以找关联厂代开合规文件" → 发货人资质链有风险，谨慎
- 报价异常低于同行 → 核对是否贸易商转单
- 爽快提供证件扫描件 → 用证号回搜官方公示做最终核验
