# 四维核验细则 + 典型翻车模式

## 证据强度分级（通用原则）

| 强度 | 定义 | 例子 |
|---|---|---|
| 铁证 | 官方登记/许可文件直接列明 | 海关注册编码、生产许可证许可范围列目标产品、环评/验收文件 |
| 强证 | 企业官方渠道明确声明 | 官网/官方展台产品页挂目标产品+唯一标识、经营范围含许可项目 |
| 弱证 | 第三方平台标签或自称 | B2B平台"工厂"标签、英文站 manufacturer 自称 |
| 无效 | 不能证明生产能力的材料 | 专利、荣誉证书、贸易流水 |

判定规则：每个维度至少一条强证以上才算 ✓；只有弱证 = 待确认；有反证 = ✗。

## 维度 1：存续

- 数据源：工商登记状态（企查查/天眼查/爱企查/国家企业信用信息公示系统快照）
- ✓：存续/在营/开业
- ✗ 直接踢：吊销、注销、经营异常（特征：吊销未注销 + 长期未年报）
- 加分信号：上市/挂牌（有公开财报约束）、成立10年+、注册资本实缴

## 维度 2：进出口资质

- 铁证：海关注册编码（搜 `{企业名} 海关注册编码`）
- 次证：经营范围含"自营和代理各类商品和技术的进出口业务"/"货物进出口；技术进出口"
- 弱证：官网自称"自营进出口权"（需交叉）
- 无进出口资质的真实厂也可保留，但标注"需外贸代理出口"，优先级降档

## 维度 3：生产资质（按品类对应的行政许可）

- 核验链条：经营范围含目标品类的许可生产项目 → 许可证书编号 → **许可范围** → 有效期
- 不同品类许可名称不同（例：生产许可证、卫生许可证、3C、特种设备制造许可、农药生产批准证等），先对齐名称
- ⚠️ 三个必查点：
  1. 有证 ≠ 能产目标产品：许可范围必须覆盖目标产品或明确包含的品类
  2. 有效期：过期证须确认续期
  3. "经营"许可证 ≠ "生产"许可证——经营许可只是能卖，不能产

## 维度 4：目标产品在产

- 铁证：公开产品清单/环评验收/排污许可列明目标产品；官方展台产品页挂唯一标识
- 强证：主营行业明确为该品类且有同系列多品种在售 → 定制能力强，标"待电话确认"
- 最终确认永远靠电话/邮件问厂（在产、起订量、包装、随货合规文件），公开信息只到"高置信候选"为止

## 分级标准

| 级别 | 条件 | 行动 |
|---|---|---|
| ★ 铁证首选 | 四维全✓，在产有铁证 | 直接询盘 |
| Tier-1 | 三证齐 + 产品页/主营铁证 | 询盘确认在产与起订量 |
| Tier-2 | 资质全，在产待确认（可定制） | 询盘问定制/增项 |
| Tier-3 | 资质强，公开文件仅证同类产品 | 低优先询盘 |
| 剔除 | 任一硬门槛✗ | 记录死因入剔除表 |

## 典型翻车模式（匿名，每条都是真实踩过的坑）

### 模式 1：专利 ≠ 生产资质
持有目标产品制备/工艺专利（常自述"适合工业化生产"），但经营范围明确"不含"该品类生产、仅有经营许可证。→ 无法作为发货人，踢。
教训：专利反向挖到的每个申请人都必须回查生产许可。

### 模式 2：许可范围差一个品名
行业头部厂、市占率高，前期像"全达标首选"。深挖许可证书后发现许可范围列了该品类 30+ 品种，**唯独没有目标产品**，且证已到期。→ 从首选降级。
教训：行业地位再高，也要逐字核对许可范围；差一个品名就差一张合法出货的门票。

### 模式 3：英文站 manufacturer 自称不可信
英文 B2B 站自称 manufacturer。工商实况：注册资本极低、实缴少、参保人数极少、注册地为写字楼、仅经营许可。→ 一人/空壳贸易商，踢。
教训：国际站线索的"工厂"属性默认为假，直到工商信息证明为真。

### 模式 4：重名混淆
搜"{产品}{生产许可}"命中的是同名异业公司（如做电子/制刷的）。→ 以统一社会信用代码对人，对不上就当无证据处理。

### 模式 5：贸易商画像速查
共同特征：经营模式标"贸易商/代理商"、经营范围带"不含{品类}"或"销售"字样、参保人数个位数、无生产地址只有写字楼、官网自述"贸易企业"。命中 2 条以上基本可判贸易商。

### 模式 6：只有经营许可的"伪装者"
有行业**经营**许可证（易误读为有资质），实际生产的是别的无关品类。→ 经营许可 + 有工厂 ≠ 生产目标产品的资质。
